# Development Logs

> **Audience**: Future-self, new contributors, anyone wanting to know "what happened".

---

## What this is

A weekly log of what was done, what's blocked, and what's next. Each week gets one file: `YYYY-MM-DD-week-NN-<topic>.md`.

## When to write

- End of every week, even if "nothing happened" (capture the blockers)
- After a major milestone (baseline reproduced, paper submitted, etc.)
- After a major debugging session (capture the root cause for posterity)

## Template

```markdown
# Week NN — YYYY-MM-DD ~ YYYY-MM-DD

> **Theme**: [One-line description of the week]

## Goals

- [ ] Goal 1
- [ ] Goal 2
- [ ] Goal 3

## Completed ✅

- [x] Task A (PR #N / commit `abc1234`)
- [x] Task B (commit `def5678`)

## In Progress 🚧

- [ ] Task C (60% done; blocked by ...)

## Blockers 🚨

- Issue X — what was tried, what's next
- Issue Y — same

## Next Week

- [ ] Task D
- [ ] Task E

## Notes / Lessons 💡

- Discovery 1
- Gotcha 2
- "If I had to do it again, I'd ..."

## Metrics / Artifacts

- Training runs: [W&B run links]
- Checkpoints: [paths]
- New code files: [list]
```
